# 吐司猫

__吐司猫__只能在创造模式中获得。

墨菲定律说，吐司总会涂有黄油的一面朝下落地，而猫总能四脚着地。把吐司绑在猫身上，就得到了学园都市对永动机的答案。

右键点击吐司猫，它会随机连接到一个范围覆盖当前位置的无线节点。再次右键点击即可断开连接。消息会显示所选节点，或说明未能连接的原因。

# 能力干涉器

当__能力干涉器__已开启且IF充足时，会阻止设定范围内、非创造模式的生存玩家使用能力。

可以通过面板开关设备，并将范围设置为10至100格。能量消耗随范围的平方增加，每10 tick结算一次。面板可以保存白名单，但当前运行逻辑不会让名单中的玩家免受干涉；请勿依赖该白名单进行保护。

# 指令

处于创造模式时，或管理员通过__/aim cheats_on__启用作弊功能后，可以使用__/aim__查看或修改自己的能力数据。仅限管理员使用的__/aimp <player>__可以编辑其他玩家的数据。

请使用Minecraft的指令建议和Tab补全查看可用的子指令与参数。本移植版没有旧版的__/aim help__子指令。

![content]
AcademyCraft的无线系统分为两层。__无线节点__把附近的发电机和机器连接成一个频道；__无线矩阵__可以将多个节点接入大型网络，并平衡各节点储存的IF。

# 无线矩阵

无线矩阵是一个2×2×2的多方块结构。运行前需要安装一个矩阵核心和三块束能金属板。核心的等级决定网络范围、节点容量和带宽。

拥有者需要在矩阵面板中设置SSID和网络密码以完成初始化。节点只有在矩阵范围内、网络仍有容量并提供正确网络密码时，才能加入该网络。

# 无线节点

无线节点分为__基础__、__标准__和__高级__三个等级。等级越高，IF缓存、带宽、范围以及可连接的机器数量也越高。

拥有者可以在节点面板中修改节点名称和密码。发电机或机器连接节点时使用节点密码；节点加入矩阵时使用网络密码。

# 连接设备

1. 要创建大型网络，先完成无线矩阵结构，并初始化SSID和密码。
2. 打开节点的无线页面，将节点连接到矩阵。数据终端中的频率变送器也可以执行无线设置。
3. 打开发电机或机器的无线页面，将其连接到范围内的节点。需要时请输入节点密码。

节点无需加入矩阵也能作为独立频道运行。加入矩阵后，会增加全网储能平衡功能，并让多个节点频道组成一个大型无线网络。

连接失败时，请检查相关面板显示的范围、连接数量上限、拥有者和密码。

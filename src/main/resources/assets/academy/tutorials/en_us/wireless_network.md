Wireless Network

![brief]
Use Wireless Matrices, Wireless Nodes, and the Frequency Transmitter to distribute IF without cables.

![content]
AcademyCraft's wireless system has two layers. A __Wireless Node__ links nearby generators and machines into a channel. A __Wireless Matrix__ can join several nodes into a larger network and balance their stored IF.

# Wireless Matrix

A Wireless Matrix is a 2×2×2 multiblock. It requires one Matrix Core and three Constraint Metal Plates before it can operate. The core's tier determines the network's range, node capacity, and bandwidth.

The owner initializes the matrix from its panel by choosing an SSID and network password. A node must be within the matrix's range, the network must have capacity, and the correct network password must be supplied before the node can join.

# Wireless Node

Wireless Nodes come in __Basic__, __Standard__, and __Advanced__ tiers. Higher tiers have a larger IF buffer, greater bandwidth and range, and can serve more machines.

The owner can change a node's name and password in its panel. The node password is used when a generator or machine connects to that node. The network password is used when the node joins a matrix.

# Connecting devices

1. To create a large network, complete a Wireless Matrix and initialize its SSID and password.
2. Open a node's wireless page and connect it to the matrix. The Frequency Transmitter in the Data Terminal can also perform wireless setup.
3. Open a generator or machine's wireless page and connect it to a node in range. Enter the node password when required.

A node can operate as a standalone channel without joining a matrix. Joining a matrix adds network-wide storage balancing and lets several node channels work as one large wireless network.

If a connection fails, check the range, connection limit, owner, and password shown by the relevant panel.

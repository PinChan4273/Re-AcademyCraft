![title]
無線ネットワーク

![brief]
無線マトリックス、無線ノード、周波数送信機を使い、ケーブルなしでIFを供給します。

![content]
AcademyCraftの無線システムは2層構造です。__無線ノード__は、近くの発電機や機械を1つのチャンネルへ接続します。__無線マトリックス__は複数のノードを大きなネットワークへまとめ、蓄えられたIFを均等に配分します。

# 無線マトリックス

無線マトリックスは2×2×2のマルチブロックです。稼働には、マトリックスコア1個と束能メタルプレート3枚が必要です。コアの種類によって、ネットワークの通信範囲、接続できるノード数、帯域幅が決まります。

設置者はマトリックスの画面からSSIDとネットワークパスワードを設定し、初期化します。ノードを接続するには、マトリックスの通信範囲内にあり、ネットワークの接続枠が空いていて、正しいネットワークパスワードが入力されている必要があります。

# 無線ノード

無線ノードには__基本__、__標準__、__先進__の3種類があります。上位のノードほどIFバッファ、帯域幅、通信範囲が大きく、より多くの機械へ接続できます。

設置者はノードの画面で、名前とパスワードを変更できます。ノードパスワードは、発電機や機械をそのノードへ接続するときに使います。ネットワークパスワードは、ノードをマトリックスへ接続するときに使います。

# 機器を接続する

1. 大規模なネットワークを作る場合は、無線マトリックスを完成させ、SSIDとパスワードを設定して初期化します。
2. ノードの無線ページを開き、マトリックスへ接続します。データ端末の周波数送信機でも無線接続を設定できます。
3. 発電機や機械の無線ページを開き、通信範囲内のノードへ接続します。求められた場合はノードパスワードを入力してください。

ノードは、マトリックスへ接続しなくても単独のチャンネルとして動作します。マトリックスへ接続すると、ネットワーク全体でエネルギーを均等に配分でき、複数のノードチャンネルを1つの大規模な無線ネットワークとして利用できます。

接続に失敗した場合は、各画面に表示される通信範囲、接続数の上限、設置者、パスワードを確認してください。

オーバーワールドには4種類のAcademyCraft鉱石が生成され、虚相位液体は物質ユニットで運べます。

![content]
AcademyCraftは、__束能メタル鉱石__、__虚能シリコン鉱石__、__虚能クリスタル鉱石__、__共振クリスタル鉱石__を追加します。サーバー設定が初期値の場合、4種類ともオーバーワールドの石層でY=0～59に生成されます。「generic.genOres」を変更しても影響するのは新しい地形生成だけで、既存のチャンクから鉱石が消えることはありません。

# 束能メタル鉱石

束能メタル鉱石の採掘には、石以上のツルハシが必要です。鉱石ブロック自体をドロップし、精錬すると束能メタルインゴットになります。束能メタルプレートは、蓄電装置、機械、そのほかの部品に使います。

# 虚能シリコン鉱石

虚能シリコン鉱石の採掘には、鉄以上のツルハシが必要です。鉱石ブロック自体をドロップし、精錬すると虚能シリコンインゴットになります。インゴットはウェイファーや虚能シリコンピースへ加工し、電子部品に使用します。

# 虚能クリスタル鉱石と共振クリスタル鉱石

どちらの鉱石も、採掘には鉄以上のツルハシが必要です。

虚能クリスタル鉱石は通常、低純度虚能クリスタルを1～2個ドロップします。虚像融合器で精製すると、より純度の高いクリスタルを作れます。

共振クリスタル鉱石は共振クリスタルをドロップします。共振クリスタルは、無線エネルギー網の周波数関連部品に使います。

# 虚相位液体

エンプティユニットで虚相位液体の水源を回収すると、虚相位液体ユニットになります。液体入りのユニットを使うと水源を再配置できます。流れている液体は回収できません。

虚相位液体ユニット1個には1,000 mBが入っています。虚相位液体は、虚相位発電機の燃料や虚像融合器の加工液として使います。

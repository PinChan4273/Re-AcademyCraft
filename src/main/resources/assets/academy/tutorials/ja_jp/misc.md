# トースト猫

__トースト猫__は、クリエイティブモードでのみ入手できます。

マーフィーの法則によればトーストはバターを塗った面を下にして落ち、猫は足から着地するといわれています。そのトーストを猫へ取り付けたものが、学園都市流の永久機関です。

右クリックすると、設置場所を通信範囲に含む無線ノードから1台がランダムに選ばれ、接続されます。もう一度右クリックすると接続を解除します。接続したノード、または接続できなかった理由はメッセージで表示されます。

# 能力干渉器

__能力干渉器__が稼働中で十分なIFを蓄えているときは、設定範囲内にいるクリエイティブ以外のサバイバルプレイヤーが能力を使えなくなります。

操作画面では、稼働のオン／オフと10～100ブロックの範囲を設定できます。エネルギー消費量は範囲の二乗に比例し、10 tickごとに消費されます。画面にはホワイトリストが保存されますが、現在の処理では登録名を除外しません。保護目的でホワイトリストに依存しないでください。

# コマンド

クリエイティブモード中、または管理者が __/aim cheats_on__ でチートを有効にした後は、__/aim__ コマンドで自分の能力データを確認・変更できます。管理者専用の __/aimp <player>__ コマンドでは、ほかのプレイヤーのデータを変更できます。

利用可能なサブコマンドと引数は、Minecraftのコマンド候補とTab補完で確認してください。旧版にあった __/aim help__ サブコマンドは、この移植版にはありません。

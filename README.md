# Re:AcademyCraft — Minecraft 26.2 / NeoForge

**Re:AcademyCraft**は、Lambda InnovationのMOD「AcademyCraft」（Minecraft 1.12.2）の、**Minecraft 26.2 / NeoForge**向けの**非公式**移植版です。
主な機能と能力の構成は、Forge 1.20.1版・NeoForge 1.21.1版の1.5.1と共通です（下の「1.5.1の内容」）。Minecraft 26.2・NeoForgeに合わせた違いがあります（下の「Forge 1.20.1版（1.5.0）との違い」）。

> **Minecraftの公式製品ではありません。Mojang・Microsoftの承認を受けておらず、提携もしていません。**
> 原作者、Lambda Innovation、MohistMC、関連作品の権利者から公認・承認・支援を受けたものでも、提携するものでもありません。

## 導入

1. NeoForge 26.2（26.2.0.93以上）を導入します。
2. `re-academycraft-neoforge-26.2-1.5.1.jar`を、クライアントの`mods`フォルダーへ入れます。マルチプレイではサーバーにも入れます。
   - 公式の導入用JARは、CurseForge（<https://www.curseforge.com/minecraft/mc-mods/re-academycraft>、Project ID `1735500`）だけで配布します。
   - 導入用JARのSHA-256: `4a6d2f7d4e619fa1b489156558191c4fb0075eab024f6e78c04a11886bf98947`
3. 更新の前に、ワールドと設定をバックアップしてください。
   - クライアントとサーバーは同じバージョンを使用してください。互換性のない通信プロトコルは接続時に拒否されます。
   - アドオンを使うときは、サーバーと参加する全員のクライアントに同じアドオンを入れてください。能力系統や技能の登録内容が一致しないと、違う能力の名前を示して接続を断ります。サーバーだけへのアドオンの導入には対応していません。
   - **NeoForge 1.21.1版やForge 1.20.1版で遊んだワールドを、この26.2版で開いたときの移行は、確認していません。** 試すときは、必ず写しで行ってください。
4. Forge 1.20.1版・NeoForge 1.21.1版のJAR（`re-academycraft-forge-1.20.1-…`、`re-academycraft-neoforge-1.21.1-…`）や、ほかのAcademyCraftと同時に入れないでください。mod IDが同じ`academy`です。

## 含まれるもの

- 能力の5系統:
  - 電撃使い（Electromaster）
  - 原子崩し（Meltdowner）
  - テレポート（Teleporter）
  - ベクトル操作（Vector Manipulation）
  - 未元物質（Dark Matter）。9種類の技能。系統は「未元物質誘導因子」で得ます（探索で見つかるチェストに入っています）
- 能力の学習と昇級: 能力開発機、プリセットと技能の操作、CP・過負荷のHUD
- CPセーフティ（CPの残りが停止ラインを下回る消費を止める。既定はONで、停止ラインは最大CPの10%）と、CPの表示の設定
- 能力ごとのプレイヤーの設定（データ端末のアプリ「能力設定」とゲーム内のコマンド。OP権限は不要。下の「能力の設定コマンド」）
- 鉱石と素材、機械、無線エネルギー、データ端末とアプリ、ゲーム内の教程（御坂クラウド）

## 1.5.1の内容

Forge 1.20.1版の公開版1.5.0（未元物質の追加、CPセーフティ、CPの表示の設定など）と同じ機能に、Forge 1.20.1版・NeoForge 1.21.1版の1.5.1と共通の次の3つの調整を足しています。

- **白翼自動防御の羽の球**: 翼で攻撃を防ぐときにできる羽の球を、羽を並べたなるべく丸い球にし、羽の先が外へ突き出さない形にしました。見た目だけの変更で、軽減の割合と費用は変わりません。
- **未元物質・甲虫生成の出現と回収**:
  - 生成した甲虫は、光の輪とともに約0.6秒かけて現れます。現れるまでの間は、動かず、攻撃の対象にもなりません。
  - スキルキーを短く押して離すと、甲虫を生成します。**キーを2秒長押しすると、全個体を回収します**（このときは生成しません）。長押しの進み具合は、照準の下に表示されます。能力設定の画面からの全個体の回収も、これまでどおり使えます。
- **白翼刺突のしなり**: 刺す翼が、相手までの距離に応じてしなり、弧を描いて刺さるようになりました。見た目だけの変更で、届く距離・ダメージ・攻撃の間隔は変わりません。

このほか、アドオン向けの演出API（`ExternalPresentation`）をバージョン3にして未元物質の演出を足し（下の「アドオンの開発（SDK）」）、通信の版を66にしました（Forge 1.20.1版の1.5.0の65とは接続できません）。

## サーバーと設定

- 能力の判定・CPと過負荷・技能の結果・機械の動作は、**サーバーが決めます**。クライアントは操作を送り、結果を表示します。

| ファイル | 内容 |
| --- | --- |
| `config/academy-common.toml` | ゲームの規則（ダメージの倍率、CP・過負荷の回復、技能の有効・無効、地形の破壊など）。 |
| `config/academy_client.properties`、`config/academy_hud.properties`、`config/academy_media_player.properties` | クライアントだけの設定、HUDの配置、メディアプレイヤーの音量など。 |

- `academy-common.toml`は**ゲームのインスタンス全体で1つ**です。シングルプレイでは、そのインスタンスのすべてのワールドに効きます。
- 専用サーバーでは、**サーバーの**`academy-common.toml`の値が使われます。サーバーへ参加したクライアントの`academy-common.toml`は、そのサーバーでは何も決めません（表示に必要な規則はサーバーから送られます）。
- ワールドごとの古い`serverconfig/academy-server.toml`は読みません。残っていると、違っている項目と移し方をサーバーの起動時にログへ出します。

## 能力の設定コマンド

Forge 1.20.1版と同じです。設定はプレイヤーのデータに保存され、死亡・再接続・次元の移動の後も残ります。データ端末のアプリ「能力設定」からも、同じ設定を変えられます（操作設定の「能力設定を開く」キーでも開けます。既定は未割り当てです）。

- **エレクトロン・ミサイル**
  - オーブは8 tickごとに生成し、8 tickごとに発射します（オーブは最大5個）。サーバーの`academy-common.toml`の`[ability.electron_missile]`の`orb_spawn_interval`（既定8、1〜40）で生成の間隔を変えられます。
  - 照準: `/academy missile mode auto|semi`。AUTO（既定）は許可された対象のうち最も近い相手、SEMI-AUTOは視線から約20°以内の相手を優先します。
  - 攻撃対象: `/academy missile target hostile|neutral|friendly|player on|off`。**既定は敵対モブだけです。** プレイヤーは`player`がONで、かつサーバーのPvPとチームの設定が許す場合だけ撃ちます。
  - 値を付けずに実行すると、今の設定を表示します。
- **ライト・シールド**
  - `/academy shield mode auto|semi`。AUTO（既定）は背後や頭上を含む周囲の脅威へ盾が自動で向きます。SEMI-AUTOは視線から約30°以内の脅威を捕捉し、約40°を超えるまで追います。従来の`manual`はSEMI-AUTOとして扱われます。
  - 盾に接触した生き物を押し戻し、自分に当たる直前で盾の円を通る飛来物を迎撃します。他のプレイヤーにも同じ盾の向きが見えます。
- **ジェット・エンジン**: 推進中、前方（視線の向きの菱形、最も広い方向で約56°）からの近接攻撃と飛来物のダメージを、熟練度に応じて10〜20%軽減します。ライト・シールドと同時に使うと、先に盾が吸収し、残りを軽減します。
- 未元物質の技能（甲虫の攻撃方針・追従開始距離・自動で狙う相手、天界発現の効果、翼の発光など）と、CPセーフティ・CPの表示は、データ端末のアプリ「能力設定」で変えます。

## 既存のワールド

- 鉱石と虚相位液体の湖は、**新しく生成されるチャンクにだけ**置かれます。
- MODを入れる前に生成したチャンクには出ません。新しいチャンクを探索してください。
- 26.2では、無線エネルギーの網とコインの台帳のファイルの置き場所が変わります。古いファイルが見つかると、新しい置き場所へ写します（古いファイルは消しません）。ほかのデータの互換を保証するものではありません。

## Forge 1.20.1版（1.5.0）との違い

- 能力の数値と既定値は、Forge 1.20.1版の公開版1.5.0と同じです。違いは、上の「1.5.1の内容」の3つの調整と、次の点です。
- **PvP**: プレイヤーへの攻撃は、Minecraft 26.2のゲームルール`pvp`に従います（チームの設定とあわせて判定します）。
- **爆発**: 公開APIによる外部の発動元の爆発のダメージは、Minecraft 26.2の計算に従い、整数に切り捨てません。同じ入力での基礎ダメージの丸めの差は1未満ですが、最終的な被害、ほかのMODの補正、押し出しが同じとは保証しません。
- **アドオンの技能の設定**: `config/academy-addon-<名前空間>.toml`の変更は、ゲームまたは専用サーバーの再起動で反映されます。ワールドの入り直しでは反映されません。
- **公開API**: アドオンの登録のイベントは`api.neoforge`にあります（Forge版は`api.forge`）。アドオンはNeoForge 26.2・Java 25向けに移植と再ビルドが必要で、Forge版やNeoForge 1.21.1版のJARはそのまま使えません。
- ライト・シールドの押し戻しで除外するボスは、NeoForgeの共通のタグ`c:bosses`で判定します（Forge版は`forge:bosses`）。バニラのボス（エンダードラゴン・ウィザー）はどちらにも入っています。
- **NeoForgeで避けられない違い**: 保存の形式（NeoForgeのattachments）、通信（Forge版のサーバーとは接続できません）、アイテムのデータ（Data Components）。Forge 1.20.1版のワールドを開いたときの移行は保証しません（上の「導入」）。
- **エネルギーユニットの作成**: 作業台では、出力1個と、残りを材料の欄へ返す形になります（Minecraft 1.21以降の制約による）。
  - 受け取れる総数、材料の数の釣り合い、バニラのクラフターでの動作は、Forge版と同じです。
  - ほかのMODの自動作成では、残りが受け取られず1個しか出ない場合があります。**ほかのMODの自動作成は保証しません。**
- **教程の表示**: ゲーム内の教程のブロックの絵は、インベントリのアイテムの絵と同じ向きで表示され、原作（少し前へ傾けた向き）と違います。

## アドオンの開発（SDK）

- 第三者のアドオンが能力のカテゴリと技能を足し、対応済みの演出を使える公開API（**実験的**）があります。開発者向けの手引きは`API_GUIDE_JA.md`です。
- SDK（APIのJAR・API sources・Javadoc・サンプルのアドオン・手引き・ハッシュの一覧）は、GitHubのrelease（<https://github.com/PinChan4273/Re-AcademyCraft/releases/tag/26.2-neoforge-v1.5.1>）のファイルとして無料で配布します。SDKのJARは導入用ではありません。
- SDKのライセンスは本体と同じGPLv3です。APIのクラスはアドオンへ入れず、実行には本体が要ります。
- **アドオンの作者へ（1.5.1の変更）**: 本体の技能「未元物質・甲虫生成」（`academy:dark_matter_beetle`）の発動方式（`ActivationKind`）は`HELD`（押し続け型）です（Forge 1.20.1版・NeoForge 1.21.1版の1.5.1も`HELD`です。Forge 1.20.1版の1.5.0では`INSTANT`（単発型）でした）。技能の定義の発動方式を読んで扱いを分けているアドオンは、この技能を押し続け型として扱ってください。公開APIの型と`AcademyApi.VERSION`（2）は変わりません。
- **アドオンの作者へ（演出APIバージョン3）**: 演出API（`ExternalPresentation`）がバージョン3になり、未元物質の7種類の演出（六翼・白翼刺突・羽の球・頭上の輪・未元空気砲の柱・甲虫の出現の輪・天界発現の予兆の輪）と未元光線を出せます。`AcademySafety.isBeam`は未元光線のダメージも光線として扱い、`skillOf`は天界発現の領域の状態異常に`academy:heaven_manifest`を返します。使う前に`ExternalPresentation.apiVersion() >= 3`を確かめてください（手引きの「未元物質の演出（演出APIバージョン3）」）。

## 既知の問題・注意

- **通信の版**: このバージョンの通信の版は66です。Forge 1.20.1版、NeoForge 1.21.1版、版65以前のRe:AcademyCraftとは接続できません。サーバーと全員のクライアントを同じ26.2版の1.5.1にそろえてください。
- **描画のバックエンド**: 確かめたのは、シェーダーパックを使わないOpenGLの描画です。
  - **Vulkan**: 開発の環境（NVIDIAのGPU 1台）で、Vulkanでも自動の試験と見た目の確かめが通りました。ほかのGPUや、Vulkanの検証の層を使った確かめはしていません。
    - NeoForge 26.2.0.93では、`config/fml.toml`の`earlyWindowControl`が既定の`true`のままVulkanを選ぶと、起動の途中で「GLFW error 65540: Vulkan: Window surface creation requires the window to have the client API set to GLFW_NO_API」という通知が出て、起動できません。NeoForgeの読み込み画面がOpenGL用の窓を作ってMinecraftへ渡すためで、Re:AcademyCraftを入れていなくても同じです。
    - Vulkanで遊ぶときは、`earlyWindowControl`を`false`にしてください（NeoForgeの読み込み中の画面は出なくなります）。Re:AcademyCraftは`fml.toml`を書き換えません。
- **シェーダー（Iris）とシェーダーパック（BSLなど）**: NeoForge 1.21.1版と同じく、シェーダーパックを使っている間だけ、能力の演出をMinecraft自身のシェーダーで描き、シェーダーパックの下でも表示されるようにしています。確かめたのは、開発の環境のIris 1.11.4（Sodium 0.9.2）とBSL v10.1.8だけです。ほかのシェーダーパックは確かめていません。
  - 光線・電弧・Jet Engineの盾・Electron Missile・Storm Wingの竜巻・Plasma Cannon・鉱物探知の枠・Light Shield・空間移動の印・甲虫の光る層・甲虫の出現と回収の輪などは、シェーダーパックの下でも表示されます。色や明るさはシェーダーパックが決めるので、シェーダーパックを使わないときと同じ見た目にはなりません（BSLでは、電弧やPlasma Cannonの竜巻が白く明るく見えます）。
  - シェーダーパックを使わないときの描き方は変えていません。
  - 未元物質の翼・防御の球・刺突・頭上の輪は、シェーダーパックを使っている間、能力の設定の「翼の発光」の100%（既定）を90%として描きます（NeoForge 1.21.1版と同じ）。100%のままでは白く飛び、形が見えなくなるためです。保存した設定は変えず、シェーダーパックを外せば100%の描き方に戻ります。90%以下にした値はそのまま使います。
  - Irisの「シェーダーの読み直し（Reload Shaders）」の既定のキーは、Iris 1.11.4でもRで、技能の3つ目の欄（既定R）と同じです。重なったときは、「設定」→「操作設定」→「キー割り当て」で、どちらかを別のキーへ変えてください。
- **既存のチャンク**: 鉱石と虚相位液体の湖は、新しく生成されるチャンクにだけ出ます（上の「既存のワールド」）。
- **ほかのMODのボス**: ライト・シールドの押し戻しで除外するボスは、共通のタグ`c:bosses`で判定します。ほかのMODのボスが除外されるかは、そのMODのタグ付けによって変わります。すべてのMODのボスとの互換は保証しません。
- **未元物質・人体生成**: ほかのMODが死亡の処理を独自に行う場合（HPを直接0にする、死亡の処理を上書きするなど）には働かないことがあります。
- **調整の可能性**: ミサイルの20°、シールドの30°・40°、ジェット・エンジンの10〜20%、敵対モブだけを撃つ既定は、Forge版と同じく、今後の試遊で調整する可能性があります。
- **原作との見た目の違い**: Electron Missileの光線の始点、Thunder Boltの範囲の弧など、一部に原作と違う見た目が残っています。
- **素材**: 原作由来の素材の一部は、作者・再配布の条件が確認できていません（下の「クレジット・ライセンス・権利」）。
- **翻訳**: 英語・簡体字中国語の文章は、母語話者による校正をしていません。気づいた点はIssueで教えてください。

## ソースからのビルド

- 必要なもの: JDK 25。初回はGradle・NeoForge・Mojangのライブラリを取得するためにインターネット接続が必要です。
- Gradle wrapper（Gradle 9.2.1）を同梱しています。

```sh
./gradlew clean build
```

- 導入用のJARは`build/libs/re-academycraft-neoforge-26.2-1.5.1.jar`です。
- 同じ場所の`-sources.jar`は導入用ではありません。
- sourceと文書はUTF-8です。Javaのコンパイルとリソースの処理にUTF-8を指定しているので、WindowsでもLinuxでも、OSの既定の文字コードに依存せずにビルドできます。
- JARはファイルの時刻と順序を固定して作ります。JDKのベンダーや版が違うと、同じsourceでもバイトが変わることがあります。
- SDKのJARは、`./gradlew apiJar apiSourcesJar apiJavadocJar`で作ります。サンプルのアドオンの作り方は`samples/academy-api-example/README.md`にあります。
- レシピ・戦利品・モデルなどのデータは、リポジトリのJSONを直接編集して管理しています（Forge 1.20.1版の生成スクリプトは、26.2のデータの形に合わないため含みません）。

# Re:AcademyCraft — Minecraft 1.21.1 / NeoForge

**Re:AcademyCraft**は、Lambda InnovationのMOD「AcademyCraft」（Minecraft 1.12.2）の、**Minecraft 1.21.1 / NeoForge**向けの**非公式**移植版です。
Minecraft 1.20.1 / Forge版の公開版1.5.0の機能を、NeoForge 1.21.1へ移したものです。1.5.1には、Forge 1.20.1版1.5.1と共通の未元物質の調整が4つ入っています（下の「1.5.1の変更」）。主な機能と能力の構成はForge 1.20.1版1.5.1と共通で、NeoForge・Minecraft 1.21.1に合わせた違いがあります（下の「Forge 1.20.1版（1.5.0）との違い」）。

> **Minecraftの公式製品ではありません。Mojang・Microsoftの承認を受けておらず、提携もしていません。**
> 原作者、Lambda Innovation、MohistMC、関連作品の権利者から公認・承認・支援を受けたものでも、提携するものでもありません。

## 導入

1. NeoForge 1.21.1（21.1.259以上）を導入します。
2. `re-academycraft-neoforge-1.21.1-1.5.1.jar`を、クライアントの`mods`フォルダーへ入れます。マルチプレイではサーバーにも入れます。
   - 公式の導入用JARは、CurseForge（<https://www.curseforge.com/minecraft/mc-mods/re-academycraft>、Project ID `1735500`）だけで配布します。
   - 導入用JARのSHA-256: `60634112052a6115edbef91b10b8b3a6858ad27771560224058f23053d96fc18`
3. 更新の前に、ワールドと設定をバックアップしてください。
   - クライアントとサーバーは同じバージョンを使用してください。互換性のない通信プロトコルは接続時に拒否されます。
   - NeoForge版1.4.1のセーブデータに無い新しい設定は、既定の値で始まります。1.5.1で開いたワールドを1.4.1へ戻すことは保証しません。
   - アドオンを使うときは、サーバーと参加する全員のクライアントに同じアドオンを入れてください。能力系統や技能の登録内容が一致しないと、違う能力の名前を示して接続を断ります。サーバーだけへのアドオンの導入には対応していません。
   - **Forge 1.20.1版で遊んだワールドを、このNeoForge版で開いたときの移行は、確認していません。** 試すときは、必ず写しで行ってください。
4. Forge 1.20.1版のJAR（`re-academycraft-forge-1.20.1-…`）や、ほかのAcademyCraftと同時に入れないでください。mod IDが同じ`academy`です。

## 1.5.1の変更

NeoForge版1.4.1からの更新です。Forge 1.20.1版1.5.0と同じ機能に、Forge 1.20.1版1.5.1と共通の調整を4つ足しています。Forge版1.5.0の変更の詳しい内容は、Forge版のrelease（<https://github.com/PinChan4273/Re-AcademyCraft/releases/tag/1.20.1-v1.5.0>）も見てください。

### Forge 1.20.1版1.5.0と同じ変更

- **新しい能力の系統「未元物質」**: 9種類の技能を、能力開発機のスキルツリーで習得できます。
  - 系統を得るには、新しい道具「未元物質誘導因子」を、能力を取得するときにインベントリへ入れておきます。誘導因子は、探索で見つかるチェストに、ほかの4系統の誘導因子と同じ割合で入っています。
  - 能力使用モードの間は、背中に六枚の白い翼が出ます。翼の光り方は、能力設定の「翼の発光」（0〜100%、既定100%）で弱められます。シェーダーで光りすぎるときに下げてください（1.5.1では、シェーダーパックの使用中は100%を自動で90%として描きます。下の「Forge 1.20.1版1.5.1と共通の調整」）。

| レベル | 技能 | 操作 | 効果 |
| --- | --- | --- | --- |
| 1 | 白翼刺突 | 長押し | 照準に向かって翼を伸ばし、連続で突き刺す。熟練度50%以上でブロックを貫通し、盾や防具などの防御を無視する。 |
| 1 | 白翼飛行 | 受動 | 翼で飛ぶ。通常飛行と、視線で操縦する高速飛行。 |
| 2 | 未元光線 | 切り替え | 六枚の翼から、照準の先へ光線を照射し続ける。照射の前に1秒のチャージがある。 |
| 2 | 白翼自動防御 | 切り替え | 受けるダメージを翼で軽減する。防ぐと、そのとき使っている攻撃の技能は中断する。 |
| 3 | 未元空気砲 | 押す | 照準を軸にした扇の範囲へ、翼から風の柱を放ち、当たった相手を吹き飛ばす。 |
| 3 | 未元装甲 | 受動 | 能力使用モードの間、受けるダメージを自動で軽減する。 |
| 4 | 未元物質・甲虫生成 | 押して離す（長押しで回収） | 未元物質の甲虫を最大3体生成する。甲虫は召喚者に追従して戦う。 |
| 5 | 天界発現 | 切り替え | 周りのチャンクを領域にし、領域の中で強化・弱体・怪現象・生き物の変異を起こす。 |
| 5 | 未元物質・人体生成 | 受動 | 致死ダメージを受けたとき、身体を未元物質で再構成し、CPを生命力にして生き延びる。 |

- **CPセーフティ**（全系統）: CPを消費した結果、残量が停止ライン以下になる場合は、その消費を止めます。停止ラインは最大CPの1〜95%（初期値10%）で、初期設定で有効です。作動している間は、CPのゲージが赤く明滅します。クリエイティブモードでは作動しません。
- **CP表示**: 能力設定で、CPの表示（ゲージのみ・ゲージと数値・数値のみ）、非使用時の表示、非使用時のサイズを選べます。
- **能力設定の画面**: 今の能力で使える項目だけを表示します。
- **状態効果の扱い**: 「身体強化」「鉱物探知」「雷撃の槍」「ライト・シールド」「フレッシュ・リッピング」の強化と弱体を、バニラの状態効果ではなく本体の直接の効果で扱うようにしました。威力・対象・確率・時間・費用は変わりません。牛乳では消えず、権限のある`/effect clear`で止まります。
- 既存の4系統・41技能の威力・射程・費用・過負荷・熟練度・入力は変えていません（上の「状態効果の扱い」と「CPセーフティ」を除く）。

### Forge 1.20.1版1.5.1と共通の調整（Forge 1.20.1版1.5.0には入っていません）

- **白翼自動防御**: 防ぐときに翼が作る羽の球を、羽でなるべく丸い球にし、羽の刃先が外へ出ない形にしました。
- **未元物質・甲虫生成**:
  - 甲虫は、生成と復帰のときに、足元の光の輪から約0.6秒かけて現れます。現れ終わるまでは動かず、戦いにも加わりません。
  - 甲虫は、技能のキーを**離したとき**に生成します。キーを**2秒長押し**すると、自分の甲虫を全部回収します。クールダウン中でも回収できます。長押しの間は、キーの案内と照準の下の帯が満ちていき、自分の甲虫の足元に輪が出ます。
- **白翼刺突**: 刺す翼が、相手までの距離に応じてしなって届くようにしました（見た目だけの変更です。届く距離・ダメージ・攻撃の間隔は変わりません）。
- **シェーダーでの翼の発光**: シェーダーパックの使用中は、「翼の発光」が100%のとき、自動で90%として描きます。100%のままでは、シェーダーパックのブルームで翼（刺突の翼と自動防御の羽の球を含む）が真っ白に光り、形が見えなくなるためです。保存された設定は100%のまま変わらず、シェーダーパックを外すと100%の光り方に戻ります。自分で90%以下にしている場合は、その値のまま描きます。能力設定の「翼の発光」の下に、この注を出します。

### アドオンの作者へ（公開APIの変更）

- 本体の技能`academy:dark_matter_beetle`（未元物質・甲虫生成）の発動方式（`SkillDefinition`の`ActivationKind`）は`HELD`（押し続け型）です（Forge 1.20.1版も1.5.1から`HELD`です）。発動方式で処理を分けているアドオンは確かめてください。
- 公開APIのバージョン（`AcademyApi.VERSION`）は2のままです。`AcademySafety.isBeam`は未元光線（`academy:dark_matter_ray`）も光線として扱い、`skillOf`は天界発現の領域の状態異常に`academy:heaven_manifest`を返します。
- **演出APIのバージョン3**（Forge 1.20.1版1.5.1と同じ）: 未元物質の演出7つ（`DARK_WINGS`・`DARK_WING_STAB`・`DARK_FEATHER_BALL`・`DARK_HALO`・`DARK_AIR_CANNON`・`DARK_EMERGE_RING`・`HEAVEN_RING`）と、光線`DARK_MATTER_RAY`を足しました。使う前に`ExternalPresentation.apiVersion() >= 3`を確かめてください（開発者向けの手引き`API_GUIDE_JA.md`）。
- **通信の版66**: 甲虫の同期データと発動方式が変わったため、通信の版を66に上げました。NeoForge版1.4.1（版64）以前とは接続できないので、サーバーと全員のクライアントを1.5.1にそろえてください。

## サーバーと設定

- 能力の判定・CPと過負荷・技能の結果・機械の動作は、**サーバーが決めます**。クライアントは操作を送り、結果を表示します。

| ファイル | 内容 |
| --- | --- |
| `config/academy-common.toml` | ゲームの規則（ダメージの倍率、CP・過負荷の回復、技能の有効・無効、地形の破壊など）。 |
| `config/academy_client.properties`、`config/academy_hud.properties`、`config/academy_media_player.properties` | クライアントだけの設定、HUDの配置、メディアプレイヤーの音量など。 |

- `academy-common.toml`は**ゲームのインスタンス全体で1つ**です。シングルプレイでは、そのインスタンスのすべてのワールドに効きます。
- 専用サーバーでは、**サーバーの**`academy-common.toml`の値が使われます。サーバーへ参加したクライアントの`academy-common.toml`は、そのサーバーでは何も決めません（表示に必要な規則はサーバーから送られます）。
- ワールドごとの古い`serverconfig/academy-server.toml`は読みません。残っていると、違っている項目と移し方をサーバーの起動時にログへ出します。

## 能力の設定コマンド

Forge 1.20.1版と同じです。設定はプレイヤーのデータに保存され、死亡・再接続・次元の移動の後も残ります。データ端末のアプリ「能力設定」からも、同じ設定を変えられます（操作設定の「能力設定を開く」キーでも開けます。既定は未割り当てです）。

- **エレクトロン・ミサイル**
  - オーブは8 tickごとに生成し、8 tickごとに発射します（オーブは最大5個）。サーバーの`academy-common.toml`の`[ability.electron_missile]`の`orb_spawn_interval`（既定8、1〜40）で生成の間隔を変えられます。
  - 照準: `/academy missile mode auto|semi`。AUTO（既定）は許可された対象のうち最も近い相手、SEMI-AUTOは視線から約20°以内の相手を優先します。
  - 攻撃対象: `/academy missile target hostile|neutral|friendly|player on|off`。**既定は敵対Mobだけです。** プレイヤーは`player`がONで、かつサーバーのPvPとチームの設定が許す場合だけ撃ちます。
  - 値を付けずに実行すると、今の設定を表示します。
- **ライト・シールド**
  - `/academy shield mode auto|semi`。AUTO（既定）は背後や頭上を含む周囲の脅威へ盾が自動で向きます。SEMI-AUTOは視線から約30°以内の脅威を捕捉し、約40°を超えるまで追います。従来の`manual`はSEMI-AUTOとして扱われます。
  - 盾に接触した生き物を押し戻し、自分に当たる直前で盾の円を通る飛来物を迎撃します。他のプレイヤーにも同じ盾の向きが見えます。
- **ジェット・エンジン**: 推進中、前方（視線の向きの菱形、最も広い方向で約56°）からの近接攻撃と飛来物のダメージを、熟練度に応じて10〜20%軽減します。ライト・シールドと同時に使うと、先に盾が吸収し、残りを軽減します。
- 未元物質の甲虫・天界発現・人体生成などの設定は、能力設定の画面で選べます。

## Forge 1.20.1版（1.5.0）との違い

- 能力の数値と既定値は、Forge 1.20.1版の公開版1.5.0と同じです。
- **1.5.1の調整**: 白翼自動防御の羽の球、甲虫の出現の演出と長押しでの回収、白翼刺突のしなり、シェーダーパックの使用中の翼の発光（上の「1.5.1の変更」）は、Forge 1.20.1版1.5.1と共通です（Forge 1.20.1版1.5.0には入っていません）。甲虫生成の発動方式は、Forge 1.20.1版1.5.0の`INSTANT`に対して、1.5.1ではどちらも`HELD`です。
- **爆発**: このAPIによる外部の発動元の爆発のダメージは、Minecraft 1.21.1の計算に従い、整数に切り捨てません。同じ入力での基礎ダメージの丸めの差は1未満ですが、最終的な被害、ほかのMODの補正、押し出しが同じとは保証しません。
- **アドオンの技能の設定**: `config/academy-addon-<名前空間>.toml`の変更は、ゲームまたは専用サーバーの再起動で反映されます。ワールドの入り直しでは反映されません。
- **公開API**: アドオンの登録のイベントは`api.neoforge`にあります（Forge版は`api.forge`）。アドオンはNeoForge 1.21.1・Java 21向けに移植と再ビルドが必要で、Forge版のJARはそのまま使えません。
- ライト・シールドの押し戻しで除外するボスは、NeoForgeの共通のタグ`c:bosses`で判定します（Forge版は`forge:bosses`）。バニラのボス（エンダードラゴン・ウィザー）はどちらにも入っています。
- **NeoForgeで避けられない違い**: 保存の形式（NeoForgeのattachments）、通信（Forge版のサーバーとは接続できません）、アイテムのデータ（Data Components）。Forge 1.20.1版のワールドを開いたときの移行は保証しません（上の「導入」）。
- **エネルギーユニットの作成**: 作業台では、出力1個と、残りを材料の欄へ返す形になります（Minecraft 1.21の制約による）。
  - 受け取れる総数、材料の数の釣り合い、バニラのクラフターでの動作は、Forge版と同じです。
  - ほかのMODの自動作成では、残りが受け取られず1個しか出ない場合があります。**ほかのMODの自動作成は保証しません。**
- 外部の主体の妨害の判定と、設置の取り消しの復元は、NeoForgeの呼ばれ方に合わせて書いています。

## 既知の問題・注意

- **Iris（シェーダー）とのキーの重なり**: 技能の3つ目の欄（既定R）と、Irisの「シェーダーの読み直し（Reload Shaders）」（既定R）が同じキーです。Rで技能を使うたびにシェーダーが読み直されて画面が一瞬止まり、押し続ける技能（プラズマ砲など）が中断されることがあります。どちらかのキーを変えてください。
  - 手順: 「設定」→「操作設定」→「キー割り当て」で、赤く表示される重なったキー（「技能の3つ目の欄」または「Reload Shaders」）を、使っていない別のキーへ変えます。シェーダーの読み直しをあまり使わない場合は、Irisの方を変えるか「割り当て無し」にするのが簡単です。
  - Re:AcademyCraftもIrisも、相手のキーを自動では変えません。
  - 確かめた組み合わせ: Iris 1.8.12・Sodium 0.6.13・BSL v10.1.8。NeoForge版1.5.1で、各系統の主な演出と、未元物質の六枚の翼・刺突・自動防御の羽の球・甲虫と出現の輪・頭上の輪が表示されることを確かめました。ほかのシェーダーパックや描画を変えるMODとの組み合わせは確認していません。
- **シェーダーでの六枚の翼の光り方**: シェーダーパックの使用中は、「翼の発光」が100%のとき、自動で90%として描きます（保存された設定は100%のままです）。100%の光り方では、BSLなどのシェーダーパックのブルームで翼（刺突の翼と自動防御の羽の球を含む）が真っ白に光り、形が見えなくなるためです。それでも光りすぎるときは、能力設定の「翼の発光」をさらに下げてください。0%では周りの明るさで照らされます（夜は暗く見えます）。
- **既存のチャンク**: 鉱石と虚相位液体の湖は、新しく生成されるチャンクにだけ出ます（上の「既存のワールド」）。
- **通信の版**: このバージョンの通信の版は66です。NeoForge版1.4.1（版64）以前や、Forge 1.20.1版とは接続できません。サーバーと全員のクライアントを同じ1.5.1にそろえてください。
- **未元物質・人体生成**: 他のMODが死亡の処理を独自に行う場合（HPを直接0にする、死亡の処理を上書きするなど）には働かないことがあります。
- **ほかのMODのボス**: ライト・シールドの押し戻しで除外するボスは、共通のタグ`c:bosses`で判定します。ほかのMODのボスが除外されるかは、そのMODのタグ付けによって変わります。すべてのMODのボスとの互換は保証しません。
- **調整の可能性**: ミサイルの20°、シールドの30°・40°、ジェット・エンジンの10〜20%、敵対Mobだけを撃つ既定は、Forge版と同じく、今後の試遊で調整する可能性があります。
- **原作との見た目の違い**: Electron Missileの光線の始点、Thunder Boltの範囲の弧など、一部に原作と違う見た目が残っています。
- **素材**: 原作由来の素材の一部は、作者・再配布の条件が確認できていません（下の「クレジット・ライセンス・権利」）。

## ソースからのビルド

- 必要なもの: JDK 21。初回はGradle・NeoForge・Mojangのライブラリを取得するためにインターネット接続が必要です。
- Gradle wrapper（Gradle 9.2.1）を同梱しています。

```sh
./gradlew clean build
```

- 導入用のJARは`build/libs/re-academycraft-neoforge-1.21.1-1.5.1.jar`です。
- 同じ場所の`-sources.jar`は導入用ではありません。
- sourceと文書はUTF-8です。Javaのコンパイルとリソースの処理にUTF-8を指定しているので、WindowsでもLinuxでも、OSの既定の文字コードに依存せずにビルドできます。
- JARはファイルの時刻と順序を固定して作ります。JDKのベンダーや版が違うと、同じsourceでもバイトが変わることがあります。
- CurseForgeで配布する1.5.1のJARは、このブランチの1.5.1のtagと同じファイル（改行はLF）からビルドしたものです。
- SDKのJARは、`./gradlew apiJar apiSourcesJar apiJavadocJar`で作ります（APIのJavadocは、Eclipse Temurinの JDK 21で作ります）。サンプルのアドオンの作り方は`samples/academy-api-example/README.md`にあります。
- レシピ・戦利品・モデルなどのデータは、リポジトリのJSONを直接編集して管理しています（Forge 1.20.1版の生成スクリプトは、1.21.1のデータの形に合わないため含みません）。
